# Departments

Department folders provide focused context without forcing every task to load the entire Company Brain. Each starter department separates framework instructions in `AGENTS.md` from company-owned purpose, leadership, priorities, constraints, authority, and context in `DEPARTMENT.md`.

- `Creative`
- `Business`
- `Product-and-Development`
- `Analytics`

Department agents read the operating system, their `DEPARTMENT.md`, and only the task-relevant canonical records. Department material should link to company, brand, product, goal, project, and decision records instead of copying them. Add more departments only when they have durable context or workflows to preserve.
