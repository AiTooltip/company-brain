# Departments

Department folders provide focused context without forcing every task to load the entire Company Brain. Each starter department has a local `AGENTS.md` that extends, but never overrides, the root operating manual.

- `Creative`
- `Business`
- `Product-and-Development`
- `Analytics`

Department material should link to canonical company, brand, product, project, and decision records instead of copying them. Add more departments only when they have durable context or workflows to preserve.
