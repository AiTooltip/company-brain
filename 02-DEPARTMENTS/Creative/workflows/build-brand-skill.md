# Build a Brand-Specific Skill

**Supported skill types:** `web-design`, `social-media`, `presentation`, `print-editorial`, `motion`

**Outcome:** create a focused, company-owned skill that changes creative execution without pretending proposals are approved rules.

**When to suggest this workflow:** before substantial branded work in a supported medium when the matching folder has no active `SKILL.md`. Explain that creating the skill first should improve the quality and consistency of both the requested task and later work, while leaving the user free to proceed with canonical brand context alone.

1. Confirm the requested skill type and read only its `SKILL.template.md`, canonical brand information, approved visual/voice direction, relevant product/goals, selected references, representative examples, dislikes, existing outputs, and explicit user preferences.
2. Separate:
   - approved brand rules;
   - reliable patterns supported by multiple examples;
   - medium-specific constraints;
   - explicit likes/dislikes;
   - proposed interpretation;
   - conflicts and missing evidence.
3. Draft concise, discriminating guidance that changes real decisions. Include sources, intended tasks, boundaries, principles, medium-specific rules, failure modes, and only examples that clarify a non-obvious choice.
4. Do not add generic creative advice, copy the entire brand guide, activate old prompts, or universalize one isolated example.
5. Show the proposed skill and its implications. Ask a human to approve, revise, or reject it.
6. Only after approval, create the real `SKILL.md` with valid `name` and discriminating `description` front matter plus status/version/approval metadata, and retain `SKILL.template.md` as inactive starter material.
7. Link canonical sources rather than duplicating them where practical. Generated `SKILL.md` is company-owned and must not be overwritten by updates.
8. Validate that the skill is scoped, discoverable, and contains no unfinished placeholders. Log activation only when it is meaningful company activity.
9. Set the expectation that activation is the start of a quality loop. Test the skill on representative tasks, collect specific feedback tied to visible output choices, and route proposed durable improvements through `refine-brand-skill.md`.
