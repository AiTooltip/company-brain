# Creative Workflows

These framework-owned workflows provide modern Company Brain equivalents for the legacy Core Brand Builder, Skill Builder, Skill Refiner, Brand Kit Builder, and design-system workflow.

They use canonical company/brand knowledge and preserve human approval. Legacy prompts remain inactive evidence.

When a branded creative request needs a missing active brand-specific skill, recommend `build-core-brand.md` for cross-medium brand direction or `build-brand-skill.md` for a supported execution medium before substantial work. Explain that quality improves through an ongoing loop of representative testing, specific output feedback, and approved changes through `refine-brand-skill.md`.
