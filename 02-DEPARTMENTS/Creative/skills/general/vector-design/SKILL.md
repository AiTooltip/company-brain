# Vector Design

Use for icons, marks, diagrams, illustrations, patterns, and other vector-native assets.

## Requirements

- Read the brief, applicable brand guidance, target sizes, color constraints, and output formats first.
- Work on a consistent coordinate/grid system appropriate to the asset.
- Prefer simple paths, shared geometry, reusable symbols, named layers, and editable strokes or fills.
- Avoid needless anchor points, accidental clipping, transforms that impair editing, embedded raster content, and unsupported effects.
- Check optical alignment, negative space, stroke behavior, corner logic, joins, caps, and scaling at intended minimum and maximum sizes.
- Keep text live when editability matters; outline it only for a specific delivery need and preserve an editable source.
- Provide accessible labels or descriptions when the vector carries meaning in a digital interface.

## Delivery

Store editable source in `09-ASSETS/source`, reviewable iterations in `09-ASSETS/working`, approved reusable assets in `09-ASSETS/approved`, and project deliverables in `10-OUTPUTS`. Record color profile, dimensions, export settings, and any font or license dependency.
