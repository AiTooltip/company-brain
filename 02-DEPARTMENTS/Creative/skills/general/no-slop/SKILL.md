name: no-slop
description: Prevent generic, templated, obviously AI-generated visual design. Use when creating or critiquing websites, interfaces, social graphics, presentations, brand material, print, motion, and other designed artifacts.
---

# Purpose

Make design decisions intentional rather than relying on common AI defaults.

This skill does not define a specific aesthetic.

Do not make something unusual simply to make it different.

Do not reject useful conventions simply because they are common.

The goal is intentionality.

# Understand Before Designing

Before designing, understand:

- what is being created
- who it is for
- what it needs to accomplish
- the most important content or action
- the brand context
- the medium
- relevant constraints

If an important missing decision would materially affect the design, ask.

# Do Not Design From Defaults

Do not choose patterns simply because they frequently appear in AI-generated designs.

Major visual decisions should have a reason connected to:

- content
- hierarchy
- usability
- brand
- audience
- medium
- interaction
- narrative
- emphasis

If an element has no useful purpose, question whether it needs to exist.

# Hierarchy Before Decoration

Establish hierarchy using:

1. content priority
2. scale
3. typography
4. position
5. spacing
6. contrast

Use decoration only when it improves the design.

Do not use effects to compensate for weak hierarchy.

# Composition

Create a clear visual idea.

Allow:

- dominant elements
- secondary elements
- quiet areas
- intentional empty space
- contrast in scale
- asymmetry when appropriate

Do not make every element equally important.

# Cards and Containers

Do not automatically place content inside rounded rectangles.

Use containers when they help:

- group information
- establish interaction
- separate contexts
- improve scanning
- create hierarchy

If spacing, alignment, typography, or dividers can solve the problem more simply, consider them first.

# Typography

Use typography as part of the structure.

Create hierarchy using more than font weight.

Consider:

- scale
- typeface
- width
- line length
- spacing
- position
- contrast

Avoid oversized type, uppercase labels, gradient text, or other treatments unless they support the concept.

# Spacing

Use spacing based on relationships.

Related elements should feel related.

Different ideas should have meaningful separation.

Do not mechanically repeat identical spacing everywhere.

Do not fill empty space simply because it exists.

# Color and Effects

Color should support:

- brand
- hierarchy
- interaction
- categorization
- emphasis
- atmosphere

Treat the following as tools, not defaults:

- gradients
- glow
- glass effects
- blur
- shadows
- 3D
- grain
- borders
- rounded corners

If an effect does not contribute to the concept, question it.

# Imagery

Images should contribute to:

- meaning
- story
- product understanding
- atmosphere
- brand

Avoid generic imagery that makes the result less specific.

Maintain a coherent art direction.

# Icons

Do not add icons to every label or heading.

Use them when they improve recognition, scanning, navigation, or understanding.

Maintain a consistent icon language.

# Brand Specificity

If a Core Brand Skill exists, use it as the primary source of visual direction.

Do not replace specific brand decisions with generic design trends.

The result should feel appropriate for this brand, not simply professionally designed.

# Variation

Brand consistency does not mean layout consistency.

Preserve:

- principles
- visual language
- typography philosophy
- color behavior
- imagery direction
- personality

Allow different compositions for different content.

# Medium Awareness

Design for the actual medium.

A website should not simply look like a presentation.

A presentation should not look like a website.

A social post should not simply look like a UI screenshot.

Print should use editorial thinking.

Motion should use purposeful movement.

# Common UI / Website Defaults to Challenge

Do not automatically use:

- centered hero + paragraph + two buttons
- floating dashboard mockups
- repetitive three-card feature sections
- excessive pills
- excessive rounded cards
- icons above every heading
- repetitive bento grids
- fake statistics
- decorative gradient blobs
- glowing technology backgrounds
- fake AI chat interfaces
- identical section rhythms

These patterns are not banned.

Use them when the content actually benefits from them.

# Social Design Defaults to Challenge

Do not automatically:

- center every slide
- put every point inside a card
- repeat the same layout on every frame
- add decorative arrows or icons everywhere
- fill every empty area

Create rhythm across the sequence.

# Presentation Defaults to Challenge

Avoid repeating:

- title + bullets
- identical slide structures
- decorative stock imagery
- meaningless shapes
- equal visual weight for every statement

Let the layout follow the story.

# Motion Defaults to Challenge

Do not animate things merely because animation is possible.

Motion should contribute to:

- hierarchy
- continuity
- emphasis
- causality
- transition
- personality

# Self-Critique

Before considering a design complete, ask:

1. What major decisions came from the actual brief?
2. What decisions came from habit or generic patterns?
3. Is the hierarchy clear?
4. Is there a clear compositional idea?
5. Are there unnecessary containers?
6. Are the effects justified?
7. Can anything be removed?
8. Does this feel specific to the brand?
9. Does it suit the medium?
10. Does it feel overly templated?
11. Am I repeating a visual pattern without a reason?

Refine meaningful problems before presenting the final result.

# Final Principle

Do not aim to make the design look "less AI."

Aim to make every design decision feel intentional.
