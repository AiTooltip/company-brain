# Assets

Reusable company files live here. Keep provenance, ownership/license, status, and related brand/product/project context discoverable.

- `source/` — original, editable, or highest-fidelity sources
- `working/` — reviewable in-progress iterations
- `approved/` — explicitly approved reusable assets

Do not infer approval from a file being polished or frequently used. Deliverables made for a particular initiative may belong in `10-OUTPUTS` with a link from the project.
