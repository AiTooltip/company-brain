# Workflows

These procedures are written for Codex but designed to remain understandable to a non-technical person. The natural-language trigger for each workflow appears near its top.

Workflows never grant approval. They inherit the human-governance, ownership, provenance, privacy, and safety rules in `11-SYSTEM/OPERATING-SYSTEM.md`.

`greet-and-orient-user.md` is the lightweight entry experience for greetings. It uses established local identity, meaningful company activity, and current work context to provide a personalized welcome without logging routine conversation.
