# System

This folder contains the AI Tooltip-owned Company Brain framework:

- `workflows/` — human-readable procedures triggered by natural-language commands;
- `templates/` — starter records for company-owned knowledge;
- `schemas/` — machine-readable shape and validation expectations;
- `scripts/` — read-only checks and framework utilities;
- `reviews/` — framework review notes, not company activity.

Most files here are framework-owned and may be proposed for update. `update-manifest.json` remains the authority. Company content created from a template is company-owned even though the template is framework-owned.
