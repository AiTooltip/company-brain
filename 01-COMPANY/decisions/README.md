# Approved Decisions

This folder is the durable decision register. Create one Markdown file per approved decision from `11-SYSTEM/templates/decision.md` and list it in the company-owned `INDEX.md`.

A proposed option is not a decision. A decision record must name the human approver, context, chosen direction, implications, any superseded records, and the approval date when recoverable. A verified historical decision may use `unknown` for its date; never invent one. If approval cannot be verified, keep the material in the relevant project as `proposed`.
