# Team

Store one shared profile per team member using `11-SYSTEM/templates/team-member.md`. Use a stable filename such as `given-family.md`.

Profiles should contain the work context AI and teammates need: role, responsibilities, working preferences, decision authority as explicitly established, and relevant contact channels. Do not use this folder for passwords, access tokens, identity documents, compensation, medical information, or unnecessary personal details.

Each computer separately identifies its active user through ignored `.company-brain/current-user.md`. Follow `11-SYSTEM/workflows/onboard-team-member.md`.
