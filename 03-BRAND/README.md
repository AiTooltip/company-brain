# Brand

Canonical home for approved brand truth. Keep core facts and principles concise here, then use:

- `guidelines/` for complete or medium-specific guidance;
- `voice/` for verbal identity, messaging, terminology, and examples;
- `visual/` for visual identity, tokens, typography, color, imagery, and design-system links.

Creative execution guidance may be distilled into `02-DEPARTMENTS/Creative/skills/brand-specific`, but canonical facts should link back here. Do not infer rules from a single old output without human confirmation.
