# Design System

This is the canonical destination for an authored visual design system, including migrated Codex Design Studio source.

It may contain:

- design tokens and themes;
- source components and tests;
- Storybook configuration, stories, and documentation;
- Theme Editor source, presets, schemas, and configuration;
- component documentation and visual-system source;
- package manifests and the applicable lockfile needed to reproduce the system.

Do not commit installed dependencies or reproducible build output such as `node_modules`, `.next`, `dist`, `build`, caches, coverage, or temporary generated files. Preserve third-party license notices and never include credentials or populated environment files.

The content placed here is company-owned. Link approved visual rules from `../README.md`, related projects, and decisions rather than copying them.
