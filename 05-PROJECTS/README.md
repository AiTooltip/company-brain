# Projects

Projects are time-bounded initiatives. Create one folder per project using a stable name such as `YYYY-project-name`, then add a `PROJECT.md` based on `11-SYSTEM/templates/project.md`.

Every active project should make its purpose, status, owner, scope, success criteria, dependencies, risks, decisions, outputs, and next checkpoint easy to find. A project may propose company changes, but it does not make them approved merely by containing them.
